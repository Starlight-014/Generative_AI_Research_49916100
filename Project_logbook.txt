Purpose of this file
--------------------
This logbook is the human-readable record of what happened to the repository and
why. Git already records what changed in each commit; this file records the things
Git cannot infer - decisions taken in conversation, problems encountered, and
what the team agreed to do next. It is deliberately plain text so that it diffs
cleanly and so that a merge conflict in it is readable rather than binary.

How to use it
-------------
Add entries at the end, newest last, one block per entry, with the date and the
author's initials. Do not reformat earlier entries: doing so turns a two-line diff
into a whole-file diff and hides what actually changed.

Numbered notes
--------------
1. The repository is organised into six numbered top-level folders, one per data
   stream, so that the tree reads in workflow order rather than alphabetically.
2. Identifiable material - signed consent forms, audio, identifiable transcripts,
   photographs of people - is never committed. It lives in UQ RDM and is referenced
   from here by pointer files. Note that a private repository does not change this:
   deleting a file in a later commit does not remove it from the history, and every
   existing clone already holds a copy.
3. All file names follow docs/NAMING_CONVENTION.md. Reviewers may reject a pull
   request on naming grounds alone.
4. Analysis outputs are regenerated by the scripts in 02_quantitative/scripts and
   are never edited by hand.
5. The main branch is protected. All work arrives through a pull request with one
   approving review. Reviewers check four things: file naming, that no restricted
   material has been added, that outputs were regenerated rather than hand-edited,
   and that the commit message explains why the change was made.

# Ethics conditions -- HREC 2026/GENAI/0417

These conditions bind everyone with access to this repository. Read them before
adding any file that came from a participant.

1. **Consent.** No data may be collected from a participant who has not signed the
   current consent form. Signed forms are held in RDM only (condition 3.1).
2. **De-identification.** Interview transcripts must be de-identified before leaving
   the RDM identifiable collection, following the documented procedure, and must be
   checked by a second reviewer (condition 3.4). See
   `../../03_qualitative/coding/GENAI_deidentification-log_20260702_v01.md`.
3. **Storage.** Identifiable data is stored only in UQ RDM. Storage on personal
   devices, personal cloud accounts or third-party repositories is not permitted
   (condition 3.2). **A private GitHub repository does not satisfy this condition.**
4. **Retention.** Identifiable data is retained for five years from publication and
   then destroyed. Audio is destroyed once transcription is verified and the paper is
   accepted (condition 4.2).
5. **Withdrawal.** A participant may withdraw up to the point of analysis. On
   withdrawal, their data is removed from the dataset and the removal is logged.
   Note that removal from a Git-tracked file removes it from the current state but
   **not from the history** -- a withdrawal affecting committed data requires the
   history to be rewritten, which is why participant-level data is committed only
   after de-identification is final.
6. **Third-party data.** No data about a person who has not consented may be entered
   into any generative AI system, including for transcription or summarisation
   (condition 3.6).
7. **Reporting.** Any breach or near-miss is reported to the HREC within five working
   days and logged in `../project_management/`.

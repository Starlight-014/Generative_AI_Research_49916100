# Project management

| File | Purpose |
|---|---|
| `GENAI_decision-log_20260905_v01.md` | Every decision that shapes the data or the analysis, and whether it was made before or after seeing the data |
| `GENAI_meeting-notes_20260908_v01.md` | Meeting records; actions are raised as repository issues, not left here |

The decision log carries a column recording whether each decision was taken before or
after the data were seen. This is the column that matters: a choice of statistic made
in the proposal and the same choice made after seeing which one gives a better result
are not the same act, and only a contemporaneous record can tell them apart.

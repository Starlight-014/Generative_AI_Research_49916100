# RESTRICTED — audio and video recordings are NOT stored in this repository

- **RDM record:** `GENAI-boon-or-bane` → collection `05_recordings`
- **Contents:** 18 interview audio files (`.wav`, ~7.9 GB total)
- **Access:** investigators who have completed transcription training
- **Disposal:** destroyed once transcription is verified and the paper is accepted

Two independent reasons keep these out of Git. First, a voice recording is
biometric and inherently identifiable regardless of what the speaker says. Second,
Git stores a complete copy of every version of a binary file, so an 8 GB audio set
would make the repository unusable for collaborators — GitHub's own limits are
100 MB per file and a 5 GB recommended maximum per repository.

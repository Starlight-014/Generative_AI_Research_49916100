Slide decks are kept in RDM rather than here. A `.pptx` is a binary that Git cannot
diff, so committing successive versions inflates the repository without producing a
readable history; the speaker notes and the figure sources, which *do* diff, are
committed instead. Figures used in slides come from
`../../02_quantitative/outputs/figures/` and are never re-exported by hand.

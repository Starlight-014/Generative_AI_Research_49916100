# 99_archive -- superseded material

Files that are no longer current but that we are not willing to delete, because a
result elsewhere in the project depends on them or because they document a decision.

Nothing here should be read as current. Every file carries the date it was
superseded and a pointer to what replaced it.

## When to archive rather than delete

Archive when the file is referenced by something already circulated -- a submitted
abstract, a seminar, a committee paper -- so that a reader of that document can still
find what it referred to.

**Delete** (and rely on Git history) when the file is simply an earlier draft. Git
already holds every committed version; copying old drafts into an archive folder
duplicates that badly, because the copies are not linked to the commits that produced
them. This folder is for things Git cannot represent, not a substitute for history.
